# Getting Started

Installation Steps:
1. Clone this environment (in command prompt, run `git clone https://github.com/justidy1/MATLAB_NEO`),
2. Change your directory into the cloned folder (i.e. `cd MATLAB_NEO`)
3. Install python depedencies with conda, where you access conda environments, run `conda env create -f environment.yml`
4. See/run example_usage.m for examples of how to load in data
